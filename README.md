## Что это

GREEN_ получает чертёж улицы (DXF или DWG: геоподоснова Мосгеотреста и подземные сети),
расставляет деревья и кустарник с нормативными отступами и объясняет каждую посадку и каждый
отказ пунктом акта: СП 42.13330, 743-ПП, МГСН 1.02-02 (623-ПП), 369-ПП. План ложится на
отдельные слои `GREEN_*` того же чертежа, исходные слои не меняются, и это проверяется после
записи. Сервис создан на конкурсе «Лидеры цифровой трансформации 2026» по задаче Департамента
природопользования и охраны окружающей среды города Москвы; команда MISIS MOJARUNG прошла в финал.

## 1. Обоснованность и актуальность

Посадку дерева у улицы ограничивают десятки нормативных расстояний: до силового кабеля,
водопровода, газопровода, теплосети, борта, опор, фасада. Чертёж одной улицы содержит сотни
тысяч объектов, и вручную нормы проверяются плохо. В посадочном плане проектировщика улицы
Берзарина 391 посадка из 554 стоит ближе нормы, 41,8% деревьев ближе 2 м к силовому кабелю.
Такое дерево не переживёт ремонт сети или повредит её корнями.

Озеленение улицы — экологическая мера: кроны снижают дневную температуру, сильнее всего при
покрытии кронами больше 40% в масштабе квартала (Ziter et al., PNAS 116(15), 2019); для здоровья
жителей рекомендуется не меньше 30% крон в каждом районе (Konijnendijk, J. For. Res. 34(3), 2023).
Ряд кустарника вдоль борта отделяет тротуар от проезжей части.

## 2. Цели и задачи

**Цель:** автоматически получать для любой улицы Москвы план посадок, который соблюдает все
нормативные расстояния, объясняет каждое решение пунктом акта и открывается в САПР
проектировщика без порчи исходного чертежа.

1. Прочитать чертёж без потерь: учёт каждого примитива, распознавание слоёв, знаков, газонов.
2. Перевести нормы в данные: 104 правила с пунктом и дословной цитатой акта.
3. Расставить посадки (аллеи, группы, изгороди, ряды кустарника, газоны, цветники) и подобрать
   вид из 58 по условиям места.
4. Независимо проверить план: отдельная проверка заново меряет все расстояния.
5. Объяснить каждую посадку и каждый отказ, без языковой модели, из трассы правил.
6. Отдать проектировщику DXF на слоях `GREEN_*`, ведомость по ГОСТ 21.508-2020, записку, 3D-вид.

## 3. Подходы, методики, решения

- Конвейер из 9 этапов: сборка комплекта чертежей, чтение без потерь, классы объектов, карта
  покрытий, индекс ограничений, варианты плана и подбор вида, независимая проверка, объяснения,
  запись DXF и сверка исходника.
- Нормы как данные: смена редакции акта — правка справочника, а не кода. Редакции СП 42.13330
  2016 и 2026 лежат рядом.
- Детерминированный алгоритм вместо «чёрного ящика»; подбор вида — целочисленное
  программирование (MILP, решатель HiGHS); портфель до 11 полных вариантов.
- Индекс качества плана из 10 слагаемых (тень, зелёный экран вдоль бортов, ярусность,
  разнообразие по правилу Santamour 10/20/30, запас до норм); веса по процедуре OECD/JRC для
  сводных индикаторов и методу анализа иерархий Саати, устойчивость — Монте-Карло.
- Локальная языковая модель только подсказывает класс незнакомого слоя; нейросеть Qwen-Image
  рисует фото будущей улицы по кадру 3D-вида.

## 4. Привлечённые ресурсы

Датасет ДПиООС (20 улиц пилотного проекта), 10 нормативных актов, официальный ассортимент
растений Москвы, OpenStreetMap. Только открытые технологии: Python, ezdxf, Shapely, SciPy,
FastAPI, React, three.js, Docker, Kubernetes. Лицензионных платежей нет.

## Новизна и тиражирование

Генеративное проектирование, где каждое решение доказуемо пунктом акта; генератор не проверяет
сам себя; нормоконтроль чужих планов теми же правилами; от чертежа до 3D и фото улицы в одном
сервисе. Подходит для любой улицы Москвы с чертежом Мосгеотреста; новая редакция норм или другой
город — правка справочников. Один образ Docker, HTTP API (OpenAPI 3.1) для встраивания.

## Развитие: модуль «Приоритет и бюджет» (прототип)

Город выбирает, какие улицы озеленять в пределах общего бюджета. Потребность улицы P (0–100)
складывается из пяти факторов с равными стартовыми весами: дефицит зелени, перегрев поверхности,
PM2.5, число жителей рядом, школы, детсады и медучреждения. Для каждой улицы GREEN_ готовит
проверенные варианты посадок, справочник цен даёт стоимость, оптимизатор выбирает лучший набор
вариантов в пределах бюджета и объясняет, почему улица выбрана или отложена. Обращения жителей
становятся кандидатами на обследование и не меняют рейтинг. Демо работает на условных данных:
показатели и цены не измерены и служат только для показа механики.
